Custom Mega Menu plugin for Elementor.

== Description ==
Mega Menu plugin for Elementor with custom widgets and advanced menu layouts.

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/my-mega-menu` directory.
2. Activate the plugin through the Plugins screen in WordPress.
3. Use Elementor widgets from the Mega Menu category.
